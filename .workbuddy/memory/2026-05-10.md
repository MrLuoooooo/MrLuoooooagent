## 多轮对话全链路修复（5月10日 后续修复）

### 修复问题
1. **SSE 响应头在 LLM 调用后才设置** → nginx 默认 60s 超时返回 504
   - 修复：`c.Writer.Flush()` 在 `ChatStream()` 之前强制发送 SSE 头
2. **prependHistory 篡改原始问题后存入 ES** → 刷新后显示 "History: user:..." 乱码
   - 修复：保存 `originalQuestion` 到 ES，LLM 用 prepended 版本
3. **第二次请求 504** → nginx `proxy_read_timeout` 60s 不够
   - 修复：nginx.conf 增加 `proxy_read_timeout 300s`
4. **ChatService 无 ConversationService 依赖** → 持久化逻辑散落在 handler 层
   - 修复：ChatService 注入 convSvc，`SaveMessages` 内部使用 `context.Background()` 避免请求上下文取消
5. **config.yaml `storage_type: "memory"`** → 与代码实际行为不一致
   - 修复：改为 `"es"`
6. **前端 convId 有值但无消息时显示空白** → 新增占位 UI 提示
